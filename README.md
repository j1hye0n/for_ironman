# Matrix Multiplication Optimization Based on HLS

Proposing HLS DSE based on a model trained with for-loop datasets.
this work was presented at 33rd Korean Conference on Semiconductor(KCS).
## Abstract

Previous research was limited to optimizing resource usage 
of basic operators such as addition and multiplication when 
generating model training data. Optimization of loops, which 
frequently appear in real-world research, was not considered.

Therefore, in this study, we extended the automatic 
optimization capability for nested loop-based code, targeting 
Matrix Multiplication — a core operation used in various 
algorithms.
